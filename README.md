# Capricorn Registration Portal UI

GitHub Pages-ready static college registration portal.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save and wait for GitHub Pages to publish.

The website entry point is `index.html`.

> Note: the current demonstration stores registration data in browser localStorage.
> It is suitable for a project/demo, not for production storage of real student
> personal information.
